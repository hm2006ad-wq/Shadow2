# Insta Creator AI — نسخة أولية

هذا مشروع خادم Node.js + واجهة HTML. ينشئ منشوراً واحداً يومياً: فكرة ونصاً من OpenAI، صورة من GPT Image، يرفع الصورة إلى Cloudinary، ثم ينشرها عبر Instagram Graph API.

## مهم قبل البدء
- يلزم حساب Instagram احترافي (Business أو Creator) مؤهل للنشر وإعداد تطبيق Meta وصلاحيات النشر المناسبة.
- هذا المشروع لا يسجل الدخول إلى Instagram بكلمة المرور. استعمل تدفق Meta الرسمي للحصول على رمز وصول ومعرّف الحساب.
- صورة Instagram يجب أن تكون على رابط HTTPS عام؛ لذلك يستخدم المشروع Cloudinary.
- مفاتيح OpenAI وMeta وCloudinary تبقى في `.env` على الخادم فقط، ولا توضع في HTML أو APK.
- النشر التلقائي قد ينشر محتوى غير مناسب إذا لم تراجع إعداد المجال والقواعد. ابدأ بالاختبار على حساب تجريبي وراقب المنشورات.
- لا يوجد ضمان أن كل عملية ستنجح؛ قد تنتهي صلاحية الرمز أو ترفض Meta المنشور أو يتعطل مزود الخدمة.

## المتطلبات
Node.js 20 أو أحدث، حساب OpenAI API، حساب Cloudinary، وإعداد Meta Instagram API.

## التشغيل
1. فك ضغط المشروع.
2. افتح مجلد المشروع في بيئة Node.js.
3. نفّذ:
   ```bash
   npm install
   ```
4. انسخ `.env.example` إلى `.env`.
5. املأ المتغيرات في `.env` بقيمك من الخدمات الرسمية. استبدل `vXX.X` بإصدار Graph API المتاح في إعداد تطبيق Meta.
6. شغّل:
   ```bash
   npm start
   ```
7. افتح عنوان الخادم في المتصفح. الجدول الافتراضي ينشر يومياً الساعة 19:00 بتوقيت الجزائر.

## اختبار النشر اليدوي
أرسل POST إلى `/api/run-now` مع ترويسة:
`x-admin-secret: القيمة الموجودة في ADMIN_SECRET`

لا تضع السر في الواجهة العامة أو داخل APK. استعمل هذا المسار من بيئة المشرف فقط.

## تحويل الواجهة إلى APK
يمكن إدخال ملفات الواجهة الموجودة في `public/` إلى HTML to APK Builder، لكن التطبيق وحده لا يشغّل الجدولة. يجب أن يبقى خادم Node.js مستضافاً ويعمل باستمرار. اجعل عنوان الواجهة يشير إلى HTTPS الخاص بخادمك.

## تخصيص المحتوى
عدّل `POST_THEME` في `.env` لتحديد مجال الحساب (مثلاً تعليم، طبخ، ألعاب، أو معلومات عامة). يختار النموذج موضوع المنشور داخل هذا المجال.
